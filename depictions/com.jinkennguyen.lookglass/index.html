Ô tìm kính lỏng trên Home, YouTube, nghe nền — và Chat cộng đồng: bấm Chat cạnh Tìm, đặt username rồi nhắn tin/link với mọi người dùng LookGlass.

Liquid-glass Home search, YouTube, background audio — plus Community Chat: tap Chat next to Search, set a username, then text/links with other LookGlass users.

Chat cộng đồng

Chat cộng đồng là phòng chat chung của người dùng LookGlass trên máy jailbreak. Tin nhắn hiện ngay. Chỉ chữ và link — không gửi hình, không gửi video.

Cách vào chat

  1. Cài LookGlass → Respring.
  2. Mở ô LookGlass trên Home → bấm Chat (cạnh Tìm).
  3. Đặt username một lần rồi vào phòng.
  4. Gõ tin hoặc dán link rồi gửi. Không cần dán URL / API key.
  5. Bấm tin của mình để Chép hoặc Xoá.

Tap Chat next to Search, set a username, send text or links. No photos.

# LookGlass changelog

Credit: Jinken Nguyen - 1989

## 4.0.1 (2026-09-22)

### Tiếng Việt
- Sửa chỉ chạy được trên iOS 15: iOS 14 không còn gắn UIWindowScene (mất ô tìm). iOS 16+ gắn đúng scene Home, cửa sổ overlay hiện và gõ được.
- WebView YouTube dùng process pool mặc định (hết load mãi trên 14 / trắng trên 16). Bàn phím iOS 16 nhận chạm.

### English
- Fixed iOS 15-only: iOS 14 no longer attaches UIWindowScene (search pill vanished). iOS 16+ binds the Home scene so overlays show and typing works.
- YouTube WebView uses the default process pool (no infinite load on 14 / blank on 16). iOS 16 keyboard taps work.

## 4.0.0 (2026-09-21)

### Tiếng Việt
- Tìm nhanh: thanh tìm + nút Tìm trên launcher. Bấm Tìm chỉ ra video YouTube, ít nhất 20 kết quả để chọn.
- Player đủ Phát/Dừng, tua ±10s, tốc độ, hẹn giờ. PiP chọn Có hình hoặc Chỉ tiếng. Tắt màn vẫn nghe. Giữ các bản sửa vuốt Home, Safe Mode, chat, trình duyệt.

### English
- Quick search: a search field plus Search on the launcher. Search lists YouTube videos only, at least 20 picks.
- Player: play/pause, skip ±10s, speed, sleep. PiP video or audio-only. Screen off keeps audio. Keeps Home-swipe, Safe Mode, chat and browser fixes.

## 3.9.5 (2026-09-21)

### Tiếng Việt
- Bấm tin nhắn hiện Xoá / Cấm / Chép / Đóng và bấm được. Alert chat không còn nuốt chạm trong SpringBoard.

### English
- Tap a chat message for Delete / Ban / Copy / Close, and the buttons work. Chat alerts no longer swallow touches in SpringBoard.

## 3.9.4 (2026-09-21)

### Tiếng Việt
- Chat cộng đồng gửi/nhận ngay: Firebase rules cho phép đăng tin, tweak không còn chờ đăng nhập hay báo URL. Chỉ cần username.

### English
- Community chat sends and receives immediately: Firebase rules allow posts, the tweak no longer waits for login or asks for a URL. Username only.

## 3.9.3 (2026-09-21)

### Tiếng Việt
- Chat dùng được chỉ với username: không còn báo nhập URL/API key. Tin gửi bằng tài khoản Firebase ẩn danh.
- Sửa bấm khoá trong khung chat bị Safe Mode (không còn PUT JSON true trần).

### English
- Chat works with just a username — no Firebase URL/API key prompt. Messages use anonymous Firebase auth.
- Fixed Safe Mode when tapping lock in the chat window (bare JSON true is no longer serialized).

## 3.9.2 (2026-09-21)

### Tiếng Việt
- Bớt tải mạng khi chưa mở chat, poll chậm hơn — đỡ lag SpringBoard.

### English
- No chat network until you open Chat, slower polling — less SpringBoard lag.

## 3.9.1 (2026-09-21)

### Tiếng Việt
- Kết nối chat cộng đồng với Firebase lookglass-jinken: rules đã publish, tin nhắn lưu realtime. Bấm Chat là dùng, không cần dán API key.

### English
- Community chat is connected to the lookglass-jinken Firebase: rules published, messages persist. Open Chat and type — no API key to paste.

## 3.9.0 (2026-09-21)

### Tiếng Việt
- Ô Chat cộng đồng jailbreak trong launcher. Chỉ nhắn tin và dán link (không hình, video). Tin lưu trên Firebase Realtime Database của bạn.

### English
- Jailbreak community Chat tile in the launcher. Text and paste links only (no photos or video). Messages are stored on your Firebase Realtime Database.

## 3.8.4 (2026-09-20)

### Tiếng Việt
- Bấm Tìm hiện danh sách cuộn ít nhất 20 kết quả ngay dưới hero, bấm là chọn. Không còn nhảy sang trình duyệt hay ô nhỏ 4–5 dòng.
- Sửa không chọn được hàng: tắt kéo-ô khi không ở chế độ Sửa, danh sách kết quả không còn bị ẩn hay đẩy xuống cuối launcher.

### English
- Search shows a scrollable pick list of at least 20 results under the hero. It no longer jumps into the browser or a 4–5 row box.
- Rows are tappable again: tile-drag is off unless Edit is on, and the results list stays pinned instead of hidden or buried.
