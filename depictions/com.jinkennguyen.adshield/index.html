AdShield 1.0.3

Jinken Nguyen - 1989 · iOS 14+ · Tweaks

Chặn quảng cáo app, Safari, WebView và video. System-wide ad blocker for jailbroken iOS.

Sau khi cài: Respring, mở Cài đặt → AdShield. Đổi tuỳ chọn xong hãy tắt hẳn app đích và Safari.

Changelog / Nhật ký phiên bản

1.0.3 2026-09-16

Tiếng Việt

  • Sửa web phim: không còn chặn poster/ảnh và HLS/mp4; video phim phát bình thường.
  • Không xoá khung player (jwplayer, video-js, #player) dù class tên ad-container/ads-box.
  • Chặn popup/popunder: chặn window.open sang domain lạ và mạng popads/propeller/exoclick.
  • Ảnh/video chỉ bị chặn khi host là mạng quảng cáo thật (doubleclick…), không chặn vì subdomain ads. của website.

English

  • Fixed movie sites: posters/images and HLS/mp4 are no longer blocked; films play.
  • Does not remove player shells (jwplayer, video-js, #player) even if named ad-container/ads-box.
  • Blocks popups/popunders: cross-site window.open and popads/propeller/exoclick networks.
  • Images/video are blocked only on real ad networks, not because a site uses an ads. subdomain.

1.0.2 2026-09-16

Tiếng Việt

  • Sửa không chặn được QC trên web và trong app; web vẫn vào được.
  • CSS/JS: nhận mẫu QC thì xoá hẳn div khỏi DOM, gấp phần trước/sau lại, không còn lỗ trống chiếm màn hình.
  • Selector QC theo token (ad-unit, ad-container, adsbygoogle…) — không khớp nhầm head-unit / upload-box.
  • Chặn thêm SDK (IMA requestAds, GAM, AppLovin, Adtima) và banner native; không chặn file HTML của website.

English

  • Fixed ads not being blocked on the web and in apps, without blocking sites from loading.
  • CSS/JS: matching ad slots are removed from the DOM and neighbors collapse so ads no longer occupy the screen.
  • Ad selectors use class tokens (ad-unit, ad-container, adsbygoogle…) and no longer match head-unit / upload-box.
  • Stronger SDK blocking (IMA requestAds, GAM, AppLovin, Adtima) and native banners; website HTML is not cancelled.

1.0.1 2026-09-15

Tiếng Việt

  • Sửa một số website bị chặn cả trang, không vào được.
  • Không huỷ navigation HTML trừ khi host là mạng quảng cáo (doubleclick, googlesyndication, …).
  • CSS không còn khớp nhầm class như head-unit, upload-box, load-overlay.
  • JS giữ khung trang (#root, #app, #__next) và khối nội dung lớn; anti-adblock không ẩn cả trang.

English

  • Fixed some websites being blocked entirely and failing to load.
  • Main-frame HTML navigation is no longer cancelled unless the host is an ad network.
  • CSS no longer matches page chrome such as head-unit, upload-box, or load-overlay.
  • JS keeps page shells (#root, #app, #__next) and large content; anti-adblock no longer hides the whole page.
