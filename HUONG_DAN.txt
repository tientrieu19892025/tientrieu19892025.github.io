5. Up thêm tweak .deb
============================================================
Cách A — từ project Theos (khuyên dùng):
  Build 3 gói rootless / rootful / RootHide vào packages/
  rồi:

     python3 scripts/update-repo.py
     git add -A
     git commit -m "Add/update <tên tweak>"
     git push

Cách B — thả file thủ công:
  Copy .deb vào debs/ với tên:
     package_version_architecture.deb
  ví dụ:
     com.jinkennguyen.miraos_2.0.0_iphoneos-arm64.deb
  rồi chạy python3 scripts/update-repo.py và git push.

IPA (TrollStore / sideload) bỏ vào extras/.
