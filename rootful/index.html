Rootful

Chỉ dùng thư mục này nếu máy của bạn đúng loại. Cài nhầm rootful/rootless/RootHide thì tweak không chạy.

← Về repo Tải tweak

Máy nào dùng Rootful?

Dùng cho: unc0ver, checkra1n, palera1n rootful, Taurine, Odyssey

Cách nhận biết: Không có /var/jb. Tweak nằm ở /Library/MobileSubstrate.

File đúng: file .deb kết thúc bằng _iphoneos-arm.deb

Do not mix folders. Rootless ≠ RootHide ≠ Rootful.

Cài bằng tay (Filza)

  1. Xác nhận máy đúng loại Rootful ở trên.
  2. Bấm Tải .deb của tweak bên dưới (Safari trên iPhone).
  3. Mở Filza → file vừa tải → Cài đặt.
  4. Respring. Mở Cài đặt → tên tweak.

Hoặc thêm source Sileo https://tientrieu19892025.github.io — Sileo tự lấy đúng loại, không cần chọn file.
