Kho Tweak Rootful

Tối ưu chính xác cho nền tảng Rootful. Không gây xung đột hay văng SpringBoard.

Xem danh sách tweak ← Về trang chủ

Khả năng tương thích

Thiết bị & Bản jailbreak: unc0ver, checkra1n, palera1n rootful, Taurine, Odyssey

Dấu hiệu nhận biết: Không có /var/jb. Tweak nằm ở /Library/MobileSubstrate.

Tên tệp chuẩn: file .deb kết thúc bằng _iphoneos-arm.deb

Hướng dẫn cài đặt nhanh (Filza)

  1. Xác nhận máy đúng chuẩn Rootful.
  2. Bấm Tải .deb của tweak bên dưới (mở bằng Safari trên iPhone).
  3. Mở ứng dụng Filza File Manager → chọn tệp vừa tải → Cài đặt (Install).
  4. Khởi động lại SpringBoard (Respring) và mở Cài đặt (Settings) để cấu hình tweak.
