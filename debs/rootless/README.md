# Rootless

Chỉ tải file trong thư mục này nếu máy của bạn là **Rootless**.

- Dùng cho: Dopamine (mặc định), palera1n rootless
- Nhận biết: Máy có thư mục /var/jb. Đây là Dopamine thông thường, không phải RootHide.
- File: file .deb kết thúc bằng _iphoneos-arm64.deb

Cài: tải `.deb` → Filza → mở file → Cài đặt → Respring.
