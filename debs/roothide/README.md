# RootHide

Chỉ tải file trong thư mục này nếu máy của bạn là **RootHide**.

- Dùng cho: Dopamine RootHide, RootHide Bootstrap
- Nhận biết: Jailbreak ẩn đường dẫn (jbroot). Sileo/Zebra của bản RootHide.
- File: file .deb kết thúc bằng _iphoneos-arm64e.deb

Cài: tải `.deb` → Filza → mở file → Cài đặt → Respring.

Sileo/Zebra: thêm `https://tientrieu19892025.github.io` — app tự chọn đúng loại, không cần tải tay.
